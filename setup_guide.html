🛠️ RADIX Talent Match — Team Setup Guide

Complete onboarding instructions to configure and run the backend microservices and frontend web app.

📋 Prerequisites

  • Python 3.10+ (Check with: python --version)
  • Node.js 18+ and npm (Check with: node -v and npm -v)
  • Git & VS Code

⚡ Step-by-Step Setup Instructions

Step 1: Backend Microservices (Terminal 1)

Open a terminal in the cloned repository and run:

# 1. Navigate to the backend directory cd backend # 2. (Recommended) Create & activate a Python virtual environment python -m venv venv .\venv\Scripts\Activate.ps1 # 3. Install all required dependencies python -m pip install --upgrade pip pip install -r requirements.txt

Create a file named .env inside the backend/ folder with the following content:

# backend/.env OPENROUTER_API_KEY= OPENROUTER_MODEL=nvidia/nemotron-3.5-super-vl:free PORT=8000

Start the backend API using python -m uvicorn:

# Using 'python -m uvicorn' avoids Windows PATH issues: python -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload
Backend Status: Live on http://127.0.0.1:8000 | Interactive API Docs: http://127.0.0.1:8000/docs

🔍 Troubleshooting Common Issues

❌ Issue 1: uvicorn : The term 'uvicorn' is not recognized
  • Why it occurs: Python packages haven't been installed yet, or Windows PowerShell doesn't have Python's Scripts directory in its environment PATH.
  • Solution: Run pip install -r requirements.txt inside backend/, and always launch via:
    python -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload
⚠️ Issue 2: Frontend Database Warning / Supabase Error Popup
  • Why it occurs: Because .env is gitignored, newly cloned repositories do not have frontend/.env.
  • Solution: Create frontend/.env with the exact Supabase credentials shown in Step 2, then restart the Vite server.
⚠️ Issue 3: PowerShell Script Execution Error (Activate.ps1 cannot be loaded)
  • Why it occurs: Windows execution policies restrict running PowerShell scripts by default.
  • Solution: In your PowerShell terminal, execute:
    Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
    Then activate again with .\venv\Scripts\Activate.ps1.
⚠️ Issue 4: Port 8000 Already In Use
  • Solution: Stop lingering Python processes in PowerShell:
    Get-Process -Id (Get-NetTCPConnection -LocalPort 8000).OwningProcess | Stop-Process -Force
